# Butter & Sugar

這是一個烘焙領域的線上課程平台，功能包含前台使用者的課程瀏覽、購買、提問，後台使用者的課程上傳、新增、編輯、問題回覆等。

## 功能特色

- 前台使用者：
  - 課程瀏覽、搜尋與分類
  - 加入購物車、下單購買
  - 提問與回覆、課程評價
- 後台講師：
  - 課程上傳、編輯與刪除
  - 回覆學員提問
- 管理者功能（未來擴充）：
  - 管理講師、使用者與訂單

## 技術架構

- node.js版本:v22.14.0
- Vue3 + Vite
- Pinia狀態管理
- UnoCSS + Naive
- TypeScript
- Axios 串接API

## 專案安裝

1.Clone 本專案

git clone https://github.com/HatchiX8/Butter-Sugar-Frontend.git

2.安裝依賴

npm install

3.啟動開發伺服器

npm run dev
